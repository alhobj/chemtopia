Senere tillatelse: «Du kan begynne å sette opp grunnstrukturen i git repoet hvis det er noe som allerede kan gjøres. Du kan også finne referansebilder til ulike deler av spillet som jeg kan velge mellom i morgen.»

Dette åpner for grunnstruktur og referansearbeid. Det godkjenner ikke automatisk uavklarte designvalg eller spillimplementering.
