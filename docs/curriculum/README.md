# Chemistry syllabus references

Consult this folder when proposing chemistry content, equipment, topics or future design questions. The selected target is IB DP Chemistry, first assessment 2025, with separate SL and HL learning paths. Exact examination years remain to be specified.

## Verified source now available

The owner supplied **Chemistry Guide 2025.pdf**. Its title and publication pages identify the International Baccalaureate's *Chemistry guide*, first assessment 2025, **published February 2023**. The PDF contains 89 physical pages. Its separation requirements, related chromatography requirements and curriculum outline have been checked directly.

Verification is against **this supplied edition**. The official website remains inaccessible from this environment, so later corrections or revisions have not been independently checked. Do not call the file the latest revised edition without evidence.

The full PDF and searchable extraction are retained locally as:

```text
docs/curriculum/private/chemistry-guide-2025.pdf
docs/curriculum/private/chemistry-guide-2025.txt
```

The private directory is ignored by Git. The public repository contains original summaries, source identifiers and page references, not the full guide or extracted full text. If these local files are unavailable in a future environment, ask the owner to supply the same source; do not pretend the public summaries reproduce the complete syllabus.

## Page conventions

**Printed page** means the page number printed in the guide footer. **PDF page** means the physical viewer page, counting the front cover as page 1. In the reviewed syllabus pages, PDF page = printed page + 6. Both are recorded to prevent ambiguity.

## Rules for future suggestions

1. Read the verified mapping and source metadata before proposing syllabus coverage. Open the local guide where available to check detail.
2. Cite edition, exact section and printed/PDF page for claims about requirements.
3. Distinguish **explicit syllabus coverage**, **practical-skill context**, **supporting knowledge**, **owner-selected examples** and **new proposals**.
4. Preserve SL/HL distinctions. An AHL label must be checked in the relevant section, not inferred from equipment complexity.
5. Use short original summaries and source references. Do not commit the full source or extraction without separate permission and appropriate rights.
6. Propose specific objectives, samples, solvents, apparatus, observations, feedback and scientific limitations for approval before implementation.
7. A syllabus requirement does not automatically belong in the first implementation increment. Retain the requested total scope while agreeing on small reviewable steps.
8. Update evidence when a later edition or correction is supplied; explain changes rather than silently expanding requirements.

This folder is a versioned working reference, not a replacement publication of the IB guide or a claim to have audited every assessment requirement.
